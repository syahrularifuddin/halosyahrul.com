**halosyahrul.com** is my personal homepage and blog: a small corner of the internet for my writing, projects, and whatever I'm currently working on.

### What you'll find here
- [Blog](/blog) — notes and write-ups, filterable by tag.
- [Portfolio](/portfolio) — selected projects with links to the source code.
- [Now](/now) — a short snapshot of what I'm focused on right now.
- [Resume](/resume) — my background in a printable format.
- [Docs](/docs) — the design system and content pipeline that power this site.

### How it's built
- **Next.js** with the App Router and React Server Components.
- **TypeScript**, **Tailwind CSS**, and **daisyUI** for the UI.
- **MDX** content, so posts and pages can embed live React components.
- Bilingual content in **English** and **Indonesian**.
- PWA-ready with offline support, a command palette, and full-text search.
- Shipped as a **Docker** image behind **Caddy**.

The source code is open on [GitHub](https://github.com/syahrularifuddin/halosyahrul.com).
